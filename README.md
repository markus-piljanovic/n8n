# n8n Workflows

Beispiel-Workflows aus meiner Automatisierungspraxis (n8n, self-hosted auf einem VPS).

## Workflows

- **E-Mail Rechnungserfassung:** liest Rechnungs-PDFs aus Gmail, extrahiert die Daten mit einem LLM, rechnet Fremdwährungen um und legt die Ergebnisse in Google Sheets sowie die PDFs in Google Drive ab.

## Hinweise

- Credentials, IDs, Tabellen- und Ordner-Referenzen sind durch Platzhalter ersetzt (`YOUR_..._ID`). Die Workflows sind so importierbar, müssen aber mit eigenen Zugängen verknüpft werden.
- Die Sticky Notes im Workflow erklären jeden Schritt.
